## 三、演示视频方案（30 秒 – 3 分钟，建议 2 分 30 秒）

**主题契合**：从一个具体时刻出发——「妈妈凌晨两点转发养生文的那个夜晚」。

| 时间 | 画面 | 台词/字幕 |
|---|---|---|
| 0:00-0:15 | 微信截图：妈妈连发 3 条养生文 + 58 秒语音；字幕"我回了 10 个『嗯』" | 痛点开场，一句戳中 |
| 0:15-0:30 | 打开家音首页，小助手挥手问候；今日卡 + 老家天气 | "它先跟我打了招呼：国庆还有 4 天，济南今天阴" |
| 0:30-1:00 | 解码器：语音输入 → 解码结果（信息压缩 + 言外之意） | "58 秒语音，翻译成 2 句话：她不是担心外卖，她是想我了" |
| 1:00-1:30 | 回音壁：三档回复 → 选"嘴硬"档 → 朗读 → 一键复制 | "馋你做的酸菜鱼了，中秋回去给我炖一锅啊" |
| 1:30-2:00 | 彩排室：挂科场景，AI 妈妈"先心疼再问情况" | "难开口的话，先和 AI 版妈妈练一遍" |
| 2:00-2:20 | 打卡徽章墙 + 合养宠物 + 分享给爸妈 | "爸妈已连续 23 天知道你很好" |
| 2:20-2:30 | 爸妈视角（小助手播报孩子动态）+ 线上地址 + slogan | 把养生文翻成关心，把"嗯"翻成"我也想你" |

**录制要点**
- **必须 ≤3 分钟**（官方硬性）；建议 2:30，信息密度高但不赶
- 用**无 Key 演示模式**录制（永不翻车）；录屏前先预热后端（Render 冷启动 30-60 秒）
- 建议竖屏 1080×1920（快手移动端观看体验最好）
- 文案需标注 AIGC 声明（发布时勾选"含AI生成内容"）
- 发布文案带话题：`#AI未来挑战赛 #AI产品实现`，可加 `#我们与AI #异地子女 #AI产品`
