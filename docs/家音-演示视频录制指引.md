> 前提：本地前后端已在运行（`http://localhost:5173`），无 API Key 也能全功能演示（演示剧本模式）。

## 一、录制前准备（5 分钟）

### 1. 一键预埋演示数据（关键！）
在 Chrome/Edge 打开：

```
http://localhost:5173/?demo=seed
```

出现「演示数据已就绪 🎬」即成功。预埋内容：
- 小档案：山东济南 / 妈的酸菜鱼 / 爸爱下象棋 / 橘猫胖虎 → 天气卡 + 个性化文案立即生效
- 连续 7 天打卡 → 首页显示 🔥7，**今天故意留空**（现场演示打卡 → 解锁「小灶火」徽章）
- 宠物「团圆」已领养、少年期、今天未喂（现场演示喂食）
- 最近动态 3 条（首页不空荡）

### 2. 环境检查清单
- [ ] 用 Chrome/Edge 全屏（F11），缩放 100%，关闭其他标签页
- [ ] 浏览器窗口调成**竖屏比例**（约 1080×1920）——比赛要求竖屏
- [ ] 提前点开麦克风权限（设置 → 隐私 → 麦克风允许；不用语音功能可跳过）
- [ ] 关闭微信/QQ 通知（录屏弹窗最致命）
- [ ] 输入法切到中文；提前把要打的句子存好（减少现场打字）
- [ ] 先全程**走一遍流程不录**，确认无卡顿再正式录

## 二、录制分镜（目标 2:30，上限 3:00）

### 口播技巧
- 不用背稿，每屏一句话，后期配字幕（剪映自动识别）
- 语气放轻，产品气质是「温柔」不是「激情带货」
- 每个模块之间停 1 秒，方便剪辑
