# 家音 · 部署与日常更新工作流

> 部署架构：GitHub 仓库（唯一代码源）→ Render（后端自动部署）+ Vercel（前端自动部署）
> **核心原则：线上永远和 GitHub 仓库一致。改任何东西，只需 commit + push，云平台自动更新。**

## 一、首次部署（只做一次）

1. **注册 GitHub**：https://github.com/signup （邮箱即可，2 分钟）
2. **建空仓库**：github.com 右上角 + → New repository → 名字 `jiayin` → Public → **不要勾选**任何初始化选项（README/.gitignore/license 都不选）→ Create
3. **推送代码**：在项目文件夹地址栏输入 `cmd` 回车，执行：
   ```
   github-push.bat 你的GitHub用户名 jiayin
   ```
   - 弹出浏览器就登录 GitHub 授权（Windows 凭据管理器会记住，以后不再弹）
4. **后端 → Render**：https://render.com → 登录（选 GitHub 登录）→ New → **Blueprint** → 选 `jiayin` 仓库 → Apply
   - 约 3-5 分钟后得到 `https://jiayin-api.onrender.com`
   - 验证：浏览器打开 `https://jiayin-api.onrender.com/api/health` 应返回 `{"status":"ok",...}`
5. **前端 → Vercel**：https://vercel.com → 用 GitHub 登录 → Add New → Project → 导入 `jiayin`：
   - **Root Directory：`frontend`**
   - Environment Variables → 添加 `VITE_API_BASE` = `https://jiayin-api.onrender.com`（末尾不带斜杠）
   - Deploy → 得到 `https://jiayin-xxx.vercel.app`
6. **回填地址**：把两个地址填进 `README.md` 的「在线体验」段，push 一次（见下）

## 二、日常更新（以后每次改代码）

在项目文件夹地址栏输入 `cmd` 回车，三步：

```
git add -A
git commit -m "说明这次改了什么"
git push
```

push 完成后：
- **Vercel 约 40 秒自动更新前端**
- **Render 约 2-3 分钟自动更新后端**
- 不需要碰任何云平台控制台

## 三、改后端必跑回归（推送前）

```
start.bat   起本地服务后，另开终端：
cd backend
.venv\Scripts\python.exe test_rehearsal.py
.venv\Scripts\python.exe test_profile.py
.venv\Scripts\python.exe test_checkin.py
```

## 四、注意事项

| 事项 | 说明 |
|---|---|
| Render 免费版冷启动 | 15 分钟无访问会休眠，首次打开慢 30-60 秒；演示前先访问一次预热 |
| API Key | 在 Render 控制台 → jiayin-api → Environment 添加 `LLM_API_KEY`；不填则自动用演示剧本（永不翻车） |
| 彩排室会话 | Render 休眠后内存清空，彩排会话丢失，属已知取舍（可加 SQLite 持久化） |
| .env 文件 | 已被 .gitignore 排除，密钥永远不会被推上 GitHub |
| 前端环境变量 | 只在 Vercel 控制台改 `VITE_API_BASE`，本地 .env.production 保持留空 |
| 国内访问慢 | 前端可迁 EdgeOne Pages（腾讯，免费）：导入同一 GitHub 仓库，构建命令 `npm run build`，输出目录 `frontend/dist`，环境变量同上 |

## 五、出问题时

- **push 报错权限**：Windows 凭据管理器 → Windows 凭据 → 删除 `git:https://github.com` 条目，重新 push 重新授权
- **Render 部署失败**：控制台看 Logs；最常见是 requirements.txt 依赖名拼写
- **前端接口 404**：检查 Vercel 环境变量 `VITE_API_BASE` 是否填对、Render 后端是否在线
