## 一、背景与痛点

中国有数以亿计的异地子女：为了学业和工作远离家乡，与父母之间只剩一块手机屏幕。这块屏幕上，每天都在上演同一种「错位的对话」：

- **父母的关心式轰炸**：《十种致癌食物千万别再吃了》的养生文、清晨五点的养生讲座、58 秒的语音方阵——子女看到的是「谣言」「打扰」，回一个"嗯"了事；
- **子女的沉默式在意**：明明想爸妈，却不知道说什么；朋友圈凌晨两点还在发，电话里只有"吃了""挺好""别担心"；
- **难开口的话越来越多**：挂科了、分手了、想辞职、生活费不够……宁可自己扛，也不敢对爸妈开口。

这不是信息问题，而是**翻译问题**：两代人都在用自己的语言说"我想你"，但对方听到的全是杂音。市面上的 AI 产品在做"更聪明的助手"，却少有人做"更懂家的翻译官"。

## 二、产品方案

「家音」站在父母与子女中间，做两件事：把父母的"关心式轰炸"翻译成子女听得懂的语言，把子女的"沉默式在意"翻译成父母读得懂的表达。

### 2.1 核心功能矩阵

| 模块 | 一句话 | 解决什么 |
|---|---|---|
| 🎧 关心解码器 | 养生文/60秒语音 → 核心信息压缩 + 情感意图 | 看懂父母没说出口的想念 |
| 💬 回音壁 | 三档温度回复（嘴硬/标准/撒娇） | 把"嗯"升级成像你说的心里话 |
| 🎭 高难对话彩排室 | AI 扮演爸妈，多轮预演难开口的话题 | 练顺了再打真电话 |
| 🎴 连心话题卡 | 4 场景 × 5 个开放式话题 | 打电话不尬聊 |
| 📷 每日安心打卡 | 拍一张今天的生活 + 一句话 | 「爸妈已连续 N 天知道你很好」 |

### 2.2 特色体验设计

- **三模块联通**：解码结果一键跳回音壁生成回复 → 复制后一键去彩排室练习，形成「听懂 → 回应 → 练习」完整闭环；
- **我家小档案**：填一次爸妈称呼、老家、拿手菜、爱好，所有生成内容自动带上你家的味道（"馋你做的酸菜鱼了"）；
- **家音小助手**：首页纯 CSS 迷你小人挥手打招呼，支持「我是爸妈/我是你」双角色——父母打开会收到热情问候，并播报孩子今天的真实动态（打卡了吗、合养的宠物长大了没）；
- **今日卡 + 老家天气**：节日倒计时制造通话契机，老家实时天气一键生成「天气问候」（"老家下雨，记得带伞"）；
- **合养小宠物**：全家的孩子——完成沟通任务赚成长值，四阶段成长、每日喂食，一键把宠物近况分享给爸妈，让 AI 陪伴变成全家的话题；
- **语音能力**：对着麦克风说就能输入，生成的回复可一键朗读试听（Chrome/Edge）；
- **最近的家音**：使用记录自动留痕，二次打开可回看，从"用一次的 Demo"变成"有回访价值的产品"。

## 三、技术架构

### 3.1 架构总览

- **前端**：Vue3 + Vite + Vant 移动端 H5，Hash 路由，纯静态部署（Vercel）；
- **后端**：Python FastAPI，9+ REST 端点（解码/回复/话题/彩排/天气），Render 云部署；
- **大模型层**：两段式提示词引擎，兼容 DeepSeek / 通义千问 / 智谱 GLM（OpenAI 兼容协议）。

### 3.2 工程亮点：无 Key 演示永不翻车

这是本作品最重要的工程设计。大模型接口存在不可控性（额度、限流、网络），而比赛演示"一次都不能翻车"。家音内置**四套离线剧本引擎**：

| 剧本库 | 规模 |
|---|---|
| 解码场景库 | 10 类父母典型消息 ×（信息压缩 + 情感解码） |
| 回音壁文案库 | 10 场景 × 3 档温度 × 画像钩子替换 |
| 话题卡题库 | 4 场景 × 5 开放式话题 |
| 彩排室对话树 | 4 场景 × 5 轮爸妈应答 |

运行时自动探测：有 `LLM_API_KEY` → 走真实大模型（画像注入提示词）；无 Key 或调用失败 → **毫秒级降级**到演示剧本（模板替换实现画像个性化），接口协议完全一致，前端无感知。此外：

- **老家天气**：Open-Meteo 免费无 Key 接口 + 「山东济南→济南」智能地理编码重试 + 失败兜底数据，三重保障；
- **画像注入**：`/api/decode|reply|topic` 均支持可选 `profile` 字段，LLM 模式注入提示词，演示模式做钩子替换（实测：排骨→拿手菜替换，旧词零残留）；
- **质量保障**：三套回归测试共 24 项（彩排室 7 项 / 画像个性化 2 项 / 打卡存储 15 项）全部通过；
- **隐私设计**：画像、历史、打卡全部存 localStorage，不上传服务器，无注册无登录即用即走。

## 四、创新点

1. **价值观创新——不辟谣，只翻译爱**：同类产品做事实核查"打脸"式辟谣，家音选择先听懂。养生文的谣言属性是传播学问题，而背后的"想你"是当下的、真实的、需要被回应的。这是对"AI 应该如何介入家庭关系"的差异化回答。
2. **产品创新——把"难开口"变成"可练习"**：彩排室首创用 AI 角色扮演预演高难对话。AI 爸妈"先心疼、再问情况"，让子女在安全的环境里把话说顺，再面对真电话。
3. **技术创新——画像个性化 + 永不翻车的降级引擎**：同一条养生文，填了档案的家庭解码出的回复带着自己家的味道；无 Key 环境下全功能可用，兼顾演示可靠性（工程价值）与 LLM 增强上限（产品价值）。
4. **机制创新——宠物 / 打卡的"父母视角"表达**：不说"我坚持打卡 N 天"，而说"爸妈已连续 N 天知道你很好"；合养宠物是"全家的孩子"而非个人游戏资产——所有激励机制都指向"让爸妈放心"。

## 五、社会价值

- **应对老龄化与空巢化**：民政部数据显示我国空巢老人占比持续攀升，异地子女规模庞大。家音降低了两代人"说爱"的门槛，改善的是数亿家庭的沟通质量；
- **情感 AI 的正确打开方式**：AI 不替代亲情，而是放大亲情——它是子女的"翻译外挂"、父母的"传声筒"，最终目的是让那通电话打得更暖、更久；
- **可持续的产品形态**：从单次工具（解码）到习惯养成（打卡）到关系沉淀（宠物/历史），具备真实的长期使用价值。
