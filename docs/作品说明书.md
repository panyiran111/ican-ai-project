## 一、产品概述

**一句话定义**：家音是一款面向异地子女与父母的 **AI 家庭沟通翻译官**——把父母转发的养生文、几十秒语音方阵翻译成子女听得懂的关心；把子女说不出口的"我在意"翻译成父母读得懂的温暖表达。

**产品主张**：父母的每一条养生文，都是没说出口的想你。
不做"辟谣打脸"式的工具，而是先听懂、再回应——谣言是传播学问题，背后的想念是此刻真实的、需要被接住的情感。

| 定位维度 | 说明 |
|---|---|
| 产品类别 | AI 原生消费级软件（移动端 H5），AI 直接参与核心服务过程 |
| 核心价值 | 降低两代人"表达爱"的门槛：听懂 → 回应 → 练习 → 陪伴 |
| 差异化 | 不辟谣、不纠正、不打脸；个性化到"你家的味道"；无 API Key 也能全功能运行 |
| 使用门槛 | 无需注册登录，打开即用；档案/记录/照片全部本地存储，不上传服务器 |

**形态与技术栈**：Vue3 + Vite + Vant（H5，7 页面）｜FastAPI（10 个 REST 端点）｜两段式提示词引擎（兼容 DeepSeek / 通义千问 / GLM）｜GitHub → Render + Vercel 自动部署。

**完成度**：五大核心模块 + 五项陪伴机制全部实现，24 项自动化回归测试全部通过，可在线体验。

## 二、目标用户

| 角色 | 画像 | 核心诉求 | 场景 |
|---|---|---|---|
| **核心：异地子女** | 18-35 岁，高校学生/职场新人，离家 300km+ | 想爸妈不会表达、怕冷场、难开口的事不敢说、被养生文轰炸又不想伤父母心 | 收到养生文的深夜、节假日前、挂科/辞职等节点 |
| **次要：父母** | 50-65 岁，空巢/独居，微信重度用户 | 想知道孩子好不好；转发消息其实想被回应；怕打扰孩子工作 | 打开产品被热情迎接、看到孩子打卡动态、接到有话题的电话 |
| **潜在：其他家庭成员** | 兄弟姐妹/祖辈 | 一起"合养小宠物"，全家有共同话题 | 家庭群分享宠物近况 |

**需求强度**：流动人口规模数亿级、空巢老人占比持续攀升 → 代际沟通是**每天发生、每次都尴尬、长期未解决**的高频场景；现有产品要么是通用助手（不懂家庭语境），要么是辟谣工具（站在父母对立面），缺少"站在两代人中间"的翻译角色；无需注册、链接即用，传播阻力极低。

## 三、核心功能

| 模块 | 一句话 | 解决什么 |
|---|---|---|
| 🎧 关心解码器 | 养生文/60 秒语音 → 核心信息压缩 + 情感意图 | 看懂父母没说出口的想念 |
| 💬 回音壁 | 按语气画像生成三档温度回复（嘴硬/标准/撒娇） | 把"嗯"升级成像你说的心里话 |
| 🎭 高难对话彩排室 | AI 扮演爸妈，多轮预演挂科/分手/辞职/要生活费 | 练顺了再打那通真电话 |
| 🎴 连心话题卡 | 4 场景 × 5 张开放式话题卡 | 打电话不再只有"吃了吗" |
| 📷 每日安心打卡 | 拍一张今天的生活 + 一句话 | 让爸妈知道"我很好"，断签不惩罚 |
| 👋 家音小助手 | 首页迷你小人挥手问候，爸妈/孩子双角色 | 让父母打开应用就被热情迎接 |
| 🌤 今日卡 + 老家天气 | 节日倒计时 + 老家实时天气与关心建议 | 给"今天该联系一下"一个理由 |
| 🐾 合养小宠物 | 完成沟通任务喂养宠物，分享近况给爸妈 | 把沟通变成全家共同话题 |

**关键设计说明**

- **解码器**：两段式（① 信息压缩：58 秒语音 → 2 句核心事实；② 情感意图：识别"她想你了"+ 建议回应点）；附**温和可信度提示**，不辟谣不打脸。
- **回音壁**：从解码结果一键跳转并预填原文；生成的三档回复注入家庭档案（实测：档案填"酸菜鱼"→ 回复出现"酸菜鱼给我留着啊"）。
- **彩排室**：AI 爸妈遵循**"先心疼、再问情况"**；说砸了可随时换场景重来。
- **小助手**：纯 CSS 动画小人（挥手/眨眼/蹦跳），父母模式会**播报孩子真实动态**（今天打卡了吗、宠物长大没）。
- **合养宠物**：沟通任务赚成长值（解码 +5 / 回音 +5 / 话题 +3 / 彩排 +10 / 打卡 +10），四阶段（幼崽→少年→成年→家人），每日喂食，断喂不惩罚。
- **打卡**：文案始终是**父母视角**——"爸妈已连续 N 天知道你很好"，而非"我坚持了 N 天"。
- **产品闭环**：收到养生文/想联系 → 解码器听懂爱 → 回音壁这样回应 → 彩排室练顺了 → 打那通电话 → 打卡/宠物沉淀关系；沟通任务喂养宠物，宠物近况又成为下一段聊天素材。

## 四、AI 的角色与价值

**AI 直接参与核心服务过程（对照官方要求）**

| AI 参与方式 | 家音落点 | 传统技术难点 |
|---|---|---|
| 理解信息 | 从 58 秒家常话抽事实 + 识别"催婚/想你了/担心身体" | 口语化无结构、含方言与情感暗示，规则引擎覆盖不了长尾 |
| 生成内容 | 按语气画像与家庭档案生成三档回复、话题卡、AI 爸妈对话 | 同一条养生文各家需要的回应不同，模板承载不了个性化 |
| 完成自然交互 | 彩排室多轮角色扮演；语音输入与回复朗读 | 需要人格一致性与情境记忆 |
| 辅助判断 | 养生文可信度分级提示 + 天气→关心建议 | 需在"科学事实"与"情感关系"间做柔性权衡 |
| 创造新体验 | "和 AI 版爸妈预演难开口的话"；宠物把 AI 陪伴转为家庭共同资产 | 需要角色扮演与情感安全的边界感 |

**AI 引擎**：两段式提示词（压缩段与情感段分离，输出稳定可解释）；画像注入（`profile` 字段，LLM 模式注入提示词 / 演示模式模板替换）；语气画像三档对应不同人格设定。

**价值主张（三个原则）**：① 不辟谣，只翻译爱；② 不替你说，教你怎么说（最终按下发送键的是你）；③ 不制造依赖，指向真实关系（彩排是为了打真电话，宠物是为了分享给爸妈）。

**AI 依赖风险的工程化解决——无 Key 演示永不翻车**：内置四套离线剧本库（解码 10 场景 / 回音壁 10×3 档 / 话题卡 4×5 / 彩排 4×5 轮），与 LLM 模式接口协议完全一致；有 Key 走大模型，无 Key 或失败**毫秒级降级**。天气接口三级兜底（免费接口 + 智能地理编码重试 + 示例数据）。

**隐私与伦理**：无注册登录、无服务端用户数据库；档案/历史/照片全存 localStorage；AI 提示词约束不评判不指责不给医疗诊断；打卡断签不惩罚、不制造焦虑。

## 五、技术实现思路

**架构**：前端（Vercel：Vue3+Vant / localStorage / Web Speech API）→ 后端（Render：FastAPI 10 端点 / CORS / 彩排会话管理）→ AI 与数据层（两段式提示词引擎 / 三家大模型可切换 / 四套剧本库 / Open-Meteo 天气）；部署流水线 GitHub → `git push` → Render + Vercel 自动重建。

| 要点 | 实现思路 |
|---|---|
| 前后端解耦与零配置部署 | 统一请求出口 `api.js`：本地走 Vite 代理，线上由 `VITE_API_BASE` 指向 Render，同一份代码两环境零改动 |
| 画像个性化链路 | 6 项家庭信息 → 紧凑摘要随请求发送 → LLM 注入 / 演示模式钩子替换（实测"排骨→酸菜鱼"，旧词零残留） |
| 彩排室会话管理 | session_id + 多轮上下文与轮次计数；过期返回 404，前端优雅兜底 |
| 语音能力 | Web Speech API 纯前端（zh-CN / continuous / 实时 interim；回复朗读可中断），不支持时 toast 降级 |
| 照片压缩与本地存储 | Canvas 缩放 640px + JPEG 0.7 存 base64；历史 50 条 / 打卡 90 天自动裁剪 |
| 天气三级兜底 | Open-Meteo 地理编码（失败做"山东济南→济南"截词重试）→ WMO 码中文映射 → 异常返回示例数据 |
| 质量保障 | 24 项回归测试（彩排 7 / 画像 2 / 打卡 15），改后端必跑 |
| 内容安全 | 提示词约束 AI 不评判、不指责、不给医疗诊断 |

## 六、应用场景示例

1. **深夜收到《十种致癌食物》**（23:40）：贴进解码器 → 解码出"她看了一整晚 + 她想你了" → 跳回音壁选"嘴硬"档 → "馋你做的酸菜鱼了，中秋回去给我炖一锅啊" → 妈妈回了个笑脸。全程没说一句"这是谣言"，但担心被看见、态度被表达。
2. **挂科了不敢打电话**：彩排室选"📚 挂科了" → AI 妈妈先起话头 → 你试着说出"妈，我挂了一门" → AI 先接情绪"没事没事，一门课而已，天塌不下来" → 练顺 3 轮后去打真电话。价值不是话术模板，而是一次低风险练习。
3. **爸妈第一次打开这个应用**：小助手主动挥手 + 切"我是爸妈"模式 → "叔叔阿姨好呀！孩子请我来陪你们聊天～" → 播报孩子真实动态"今天打卡报平安啦，还写了句『食堂的糖醋排骨，想到妈做的了』" → 看到"爸妈已连续 23 天知道你很好" → 点话题卡打过去不冷场。
4. **中秋回家前的通话预热**：今日卡提醒"国庆还有 4 天" + 老家天气"济南 27.2℃ 阴" → 一键生成天气问候 → 抽话题卡"爸最近钓到大家伙了没？"（结合爸爸爱好）→ 通话聊了二十多分钟。
5. **全家合养一只小宠物**：接一只"团圆" → 每次好好说话它就长大 → 分享"我们家猫『团圆』现在是成年啦～"到家庭群 → 妈妈开始追问"它吃饭了吗"。

## 七、创新性、完成度与孵化潜力

**创新性**：① 价值观——不辟谣只翻译爱；② 产品——把"难开口"变成"可练习"；③ 技术——个性化注入 + 永不翻车降级引擎；④ 机制——"父母视角"的激励设计；⑤ 体验——让父母被热情迎接。

**完成度**：8 项主要能力全部实现；在线可体验；无 Key 全流程可演示；24 项回归测试通过；390px 移动端适配；无账号体系、无服务端用户数据、无第三方素材。

**孵化潜力**：C 端家庭订阅（档案云同步 / 多成员合养 / 节日话题包）；B 端银发关怀、社区养老、心理健康教育、企业 EAP；从工具 → 习惯 → 关系沉淀的留存路径；离线剧本库大幅降低大模型运营成本。
