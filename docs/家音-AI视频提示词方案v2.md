# 家音 · AI 视频提示词方案 v2（返工修正版）

> 修正 5 处错误：否定句移入负向提示词、删除画幅描述、单段单动作、拆掉转场、精简字数
> 适用于：可灵 AI（推荐，快手官方）/ 即梦 AI / 剪映 AI 创作

## 〇、每次生成前必设的参数（重要）

| 参数 | 设置 |
|---|---|
| 画幅比例 | **9:16**（工具里选，别写在提示词里） |
| 时长 | 5 秒（或 10 秒，选短的） |
| 负向提示词 | 见下方「通用负向提示词」，每段都要填 |
| 生成数量 | 每段生成 2 条，选好的一条 |

### 通用负向提示词（复制到工具的「负向提示词/不希望呈现」输入框）
```
文字，字幕，水印，logo，乱码，字母，数字，手机界面，屏幕内容，多余的手指，畸形的手，扭曲的脸，模糊，低质量
```

### 角色锚点（正向提示词里逐字保留，保证跨镜头是同一人）
- 儿子：「22岁中国男大学生，黑色短发，深灰色连帽卫衣」
- 妈妈：「55岁中国母亲，齐耳短发有少许白发，枣红色针织开衫」

## 二、每段生成后的检查清单（选片用）

- [ ] 画面里**没有任何文字/乱码**（有就重生成，或负向提示词没填）
- [ ] 人物手指、面部正常无畸变
- [ ] 角色特征与锚点一致（黑短发灰卫衣 / 白发红开衫）
- [ ] 动作幅度小、镜头稳（AI 不擅长大动作）
- [ ] 手机屏幕是光晕或背对镜头（看不清界面内容才算过）

## 三、不合格时的抢救技巧

| 症状 | 处理 |
|---|---|
| 出现乱码文字 | 负向提示词补「中文，汉字」再生成 |
| 人脸每次不一样 | 可灵用「尾帧/参考图」：先文生图一张角色定妆照，再用图生视频，8 段全用它当参考 |
| 动作太大崩坏 | 把动作描述删到只留一个动词（如只留「微笑」删掉其他） |
| 画面发灰 | 提示词末尾补「暖色调，电影级打光」 |

## 四、产品操作段仍用真实录屏（不变）

解码/回音/彩排三段用已有录屏，剪映套手机边框贴纸。原因同前：AI 画界面必错版。

## 五、生成顺序建议

先只生成**片段 1**，按检查清单验收通过后，再批量生成其余 7 段——避免一条提示词有问题导致 8 段全部返工。
